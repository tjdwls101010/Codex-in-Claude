# 설계 기록

이 레포의 변경이 "왜 그렇게 됐는지"가 사는 곳이다. 계약은 `.claude/harness-spec.md`에 있고, 여기 있는 건 그 계약에 도달하기까지의 추론이다.

## 두 자리

**루트는 인박스다.** Claude Code 플랜 모드는 새 플랜을 이 디렉터리 루트에 `lively-toasting-wadler.md` 같은 자동 생성 이름으로 떨군다. 진행 중인 작업의 플랜은 여기 있다.

**`YYMMDD/`는 정리된 기록이다.** 작업이 머지되면 그 플랜을 날짜 폴더로 옮긴다. 같은 라운드가 낳은 다른 문서들(감사 기록, 인벤토리, 조사 목록)도 같은 폴더에 들어간다. 날짜는 작업이 시작된 날이다.

파일명은 옮길 때 바꾸지 않는다. 자동 생성된 슬러그도 그대로 둔다 — `.claude/histories`의 세션 로그와 1:1로 대응하기 때문이다.
